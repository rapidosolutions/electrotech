# Electro Tech design system

## Direction

“Solar Contemporary” combines warm editorial space, direct solar photography, restrained geometry and a clear conversion path. Solar carries the strongest visual weight; electrical and security work support it.

## Tokens

- Colors: warm white `#F6F5F0`, deep forest `#102A1B`, solar lime `#CBEA22`, energy orange `#F27432`, sage `#E7ECCE`, solar sky `#DDEBF0`.
- Type: Geist, with a fluid `clamp()` scale; headings use compact line-height and modest negative tracking.
- Container: `1280px` maximum with `24px` desktop and `16px` mobile gutters.
- Spacing: section padding scales from `82px` to `170px`.
- Radius: mostly square editorial surfaces; `16–28px` for utility, `80–140px` for selected image corners.
- Border: forest at 16–22% opacity.
- Shadow: soft forest-tinted elevation, used only for overlapping imagery and the hero.
- Motion: 120–200ms micro-interactions, 450–700ms hero reveals; all disabled under reduced motion.
- Breakpoints: 1024px for navigation/tablet layout, 800px for single-column composition, 520px for compact mobile refinements.
